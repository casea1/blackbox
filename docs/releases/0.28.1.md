## What's fixed

- **Trends:** "Detections by system, by week" lists systems by name (WS-2 before WS-10), as the other pages do, instead of by most detections this week. Systems with no detections stay folded under "All N", also by name.
- **People, Notable actions:** in weekly and monthly reports the time ("Mon 09:20") no longer runs into the system name.
- **System page, Detections:** the time ("Mon 28 Sep 12:38") no longer runs past the panel's edge.
- **Detections list:** the system and time now sit under each title, so titles are no longer squeezed onto several short lines. The selected detection is no longer drawn as a narrow box.
