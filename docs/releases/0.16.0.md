## What's new

This release covers the UI/UX review of 0.15.0 (UI1–UI8). Blackbox still only reports; it changes no system or audit settings.

### Trends by calendar week (UI1, UI8)

- **Calendar weeks, not reports.** Each scheduled report now keeps its counts day by day (`days` in `summary.json`). Trends, What changed, the Overview's small charts and All reports' "Detections per week" add them up by Monday-to-Sunday week, so a long first report, daily reports and weekly reports are compared fairly.
- **Manual reports are never part of the history.** Running `blackbox report` or **Make a manual report…** in the tray never adds a bar.
- **The current week is "so far".** For example, "so far this week (2.5 of 7 days)" is compared with the same share of the average.
- **Partial weeks only from the first report.** Its days count only as partial weeks, which are labelled "(part)" and not compared.
- **Not enough history yet.** Until there are 2 full weeks, Trends, What changed and All reports say "Not enough history yet: trends start after 2 full weeks" instead of drawing a chart.
- **Labelled axes.** They show the week's dates ("14–20 Sep", "This week (so far)"), with "Last N weeks" above the chart.
- **Earlier summaries.** Reports made before 0.16 are used only when their period lies within one week.

### Saying when a computer stopped sending (UI2)

- **A virtual machine is one that says so.** A sender that delivers through a VirtualBox shared folder marks its batches as a VM. Data relayed through another computer no longer makes a VM.
- **A VM that sent nothing all period** is **Worth a look: nothing received since 5 Oct 06:31** and isn't counted as reporting. A VM that was off for part of the week is still fine.
- **Any other computer that sent nothing** is **Silent**.
- **Inventory's "No inventory yet"** gives each system's reason:
  - it has sent nothing since a given time;
  - it runs a Blackbox from before 0.13;
  - it has sent no settings check yet.

### Blackbox's own installer (UI4)

- `Blackbox-Setup-<version>.exe` writing `C:\ProgramData\Blackbox` (and `blackbox.conf.new`) is no longer a row, nor a step of **Possible covering of tracks**. This applies when the same computer has Blackbox's own record of that install or upgrade.
- A program with that name and no such record still shows as High.

### Layout and wording (UI3, UI5, UI6, UI7)

- **Audit health (UI3).** "Every system, every check" takes the full width, with Gaps below it.
  - Headings are short; hover one for its full name.
  - The System column stays in view.
  - While the grid still scrolls sideways, it says **more →**.
- **A manual report's Original logs page (UI5)** no longer shows empty tiles. It says:
  - where the logs wait (`archive_dir`);
  - the period and size so far;
  - which scheduled report will hold them.
- **All reports (UI6).** A single day is shown as one date ("5 Oct 2026"). A period that starts or ends during a day shows its times ("5 Oct 00:00 – 06:44"). Numbers have thousands separators everywhere ("95,229 events lost").
- **Smaller fixes (UI7):**
  - Trends' after-hours card says "Set working_hours to see this".
  - Inventory and Audit health keep their buttons beside the title.
  - Overview system tiles show whole names, with the full name on hover.
  - "Logs too small" is now **Log size and space settings**.

### Not verified live

- The VM flag on a real VirtualBox shared folder. Senders older than 0.16 send no flag, so their VMs show as workstations until they are upgraded.
- Reinstalling the *same* version records no install, so that installer's writes would still show.
