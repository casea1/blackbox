## What's new

Follow-ups on 0.16.0 (UI9–UI12). Blackbox still only reports; it changes no system or audit settings.

### The Overview checklist says what went wrong (UI9)

A failing line no longer keeps its passing title. "No events lost to log rollover" above "95,229 events were overwritten" is now **Events lost to log rollover**, naming the systems. The same applies to:
- **Logs cleared**
- **Not every system reporting**
- **Events arrived late**
- **Audit settings to fix**
- **Original logs missing**
- **Antivirus needs attention**

These titles appear on the Overview and in each system's health list.

### Audit health: Antivirus and SCAP in reach (UI10, UI11)

- **"Every system, every check" is now "Audit settings by system".** Systems with a gap or warning are listed; those that match on every check are folded under **Show the N systems that match on every check**.
- **A bar at the top of the page** links to each section (the grid, Gaps, Antivirus, STIG compliance, other Security-log events) and says what needs attention in each.
- **Antivirus** lists out-of-date systems first; those with current definitions are folded the same way.
- **STIG compliance (SCAP)** shows each system's operating-system STIG (Windows, Ubuntu, RHEL, Alma and so on), with open CAT I first. Other benchmarks scanned on the same systems (Edge, Firefox, Defender…) are under **Other benchmarks**, one click away. The open-rules CSV still lists them all.
- **Systems with no scan** are named in one line instead of a row each.

### Inventory drives (UI12)

Each system's drives, with serial number, size and type, are now in its row of the Inventory table. Clicking a system shows its accounts at full width.

Release files are still unsigned: the signing secrets (A10) have not been set yet.
