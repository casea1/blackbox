## What's new

Fixes from the 0.19.0 deep test (7 Oct 2026): the original logs, log clears and losses, Audit health and roles, small console and tray items, and a cleaner report. Blackbox still only reports; it changes no system or audit settings.

### Original logs are archived even when a piece is lost (AR5, AR6)

- One deleted or unreadable export no longer stops this computer's original logs from being archived. It is left out and recorded in `archive.json` as a gap, with its log, period and reason. The rest is packed.
- If packing fails altogether, `blackbox status` says **ORIGINAL LOGS NOT ARCHIVED since …: …** and exits 4. The status icon notifies once, and the report shows the reason on Original logs and in Audit health.
- Each export is hashed when it is written. One changed before packing is archived as it was found, marked `changed`, and becomes a High detection.
- On Linux, `blackbox check --audit-rules` adds a rule that watches the exports folder for writes by anything but Blackbox, including a root script. Load it with `blackbox check --audit-rules --missing`.

### Scheduled reports are checked file by file (LEDGER1, LEDGER2)

- Every run checks that each file a scheduled report's manifest lists is still there, at its size. Once a day, every file is hashed again.
- `status` names the file, e.g. "REPORT CHANGED: … logs-WS-07.zip is missing".
- A report accepted as moved keeps its row on All reports, muted: "Accepted as moved by … on …: …".

### Log clears and losses (LC1, LC2, LOG1b, TIME1)

- A cleared log is named: "PowerShell log cleared" for a System 104. "Security log cleared" stays for 1102.
- A cleared log is no longer also counted as lost to rollover, and gets no size advice.
- `status` and `check` now give the same size, capped at 2 GB. The registry advice fits a REG_DWORD.
- Only the audit record's log (Security, or the Linux audit log) makes **LOGS INCOMPLETE** exit 4. Another log's line, such as the PowerShell log's, does not.
- "Collect more often" is suggested only when it would help.
- A person moving the clock by more than 5 minutes is now a detection: High when moved back, Medium when moved forward. The sub-second 4616 that each `Set-Date` logs is no longer a row.

### Audit health and roles (STIG1, ROLE1)

- A gap that systems share under different STIGs lists each one's IDs, with its OS.
- A collector made standalone no longer reports on its former senders once they have sent nothing in the period.

### A simpler report (UX1–UX9, AR2c)

- **Repeats are one row.**
  - The console host (`conhost.exe`) Windows starts for each elevated console program is folded into the row of the program that started it.
  - Identical records within a minute become one row marked **×N**, with each time in the details.
  - Every count is a count of rows.
- **Each fact once.**
  - The Overview has four headline numbers for this report (systems reporting, detections, events, audit health), only the activity counters that aren't zero, and Health with each problem once.
  - The Systems page gives the settings to fix as a count that links to Audit health.
- **Two words: Detections and Health.** Every High event is in a detection, so the High count and the Detections count now agree. `summary.json`'s `high` counts High detections.
- **Audit integrity** labels each row by kind (Blackbox, Firewall, Clock, …). The Logging stopped tile counts only real stops.
- **Less clutter.**
  - Empty event pages are one line.
  - Columns that are the same on every row are hidden.
  - A one-day report is charted by hour.
  - "Above normal" is shown only when there is something to compare with.
  - "Not enough history" is said once.
- **Navigation.**
  - The sidebar is Overview, Detections, Search, Systems, People, Audit health, Original logs and All reports. The event pages are under **Events by kind**, and Inventory and Trends under **More**.
  - Search has the kinds of event as chips with their counts.
  - A manual report's banner is on the Overview, with a chip on every other page.
- **SSH logons on Windows** show their source address, read from the OpenSSH server's log.
- **Privileged actions** now count people's actions, as Trends' by-person table does. Counts in earlier reports are unchanged.
- **Blackbox's own exports are no longer High rows** in a manual report made right after a run (AR2c).

### Smaller

- The status icon's tooltip says "something to look at: see Status details".
- At phone width, wide tables scroll inside their panels.
- A command refused its settings says to run it with `sudo` (or from an administrator prompt).
- On Windows, output redirected to a file is plain ASCII.
- `install` on Windows starts a collection, as on Linux.
- `config set keep_sent_days 0` says it ends resends.
- The `blackbox.conf` template no longer says collection is hourly.

Release files are still unsigned: the signing secrets (A10) have not been set yet.
