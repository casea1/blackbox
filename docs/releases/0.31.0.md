## What's new

### Opening the reports on Linux (READ1)

The reports folder is root's, so auditors couldn't open a report without sudo. Ubuntu's snap Firefox couldn't open one at all, because it can only read files in the home folder.

- **Who can open the reports.** Setup asks for a Linux group, such as `sudo` or `wheel`. Its members can read the reports but not change them. After every run, new report files are given to that group. Setup also says if a folder above the reports folder keeps the group out. Upgrades ask this once. Setting: `report_group`.
- **Blackbox reports** is now in the applications menu, and you can pin it to the dock. A click opens the latest report. Right-click offers **Open the reports index** and **Make a report now** (which asks for an administrator's password).
- **`blackbox open`** (or `blackbox open --index`) opens the latest report in your own browser, without sudo. When the browser is a snap, the reports are copied to `~/Blackbox reports` first. Each report is copied once; the original-log zips are not copied.

## Security: folders and permissions (SEC7–SEC10)

A review of every place Blackbox makes, reuses or changes folders, files and permissions found these. All are fixed:

- **SEC7 (high, Linux collector):** a sender could make its own `rejected` folder or old-style sender folder in the inbox, then swap it for a link to `/etc` while the collector was clearing it. The collector, running as root, would then move or delete system files. The collector now clears only folders it made itself.
- **SEC8 (high, Windows):** any user could create `C:\ProgramData\Blackbox` before setup, with access of their own that setup kept. They could then change the settings, or the scheduled task's definition before it was registered. Setup now makes Administrators the owner of the folder and everything in it, and replaces its access list. The task definitions are written under new random names in that folder; the tray task's used to be a fixed name in `%TEMP%`.
- **SEC9 (medium, Linux):** an existing report or original-logs folder that others could write to was used as it was. A local user could plant a link where root would write next. Setup now makes such a folder root's and takes away write access for group and others (reading is unchanged), and says so. Temporary report and archive files are always made new, never through a link. On Windows, setup warns when accounts other than Administrators can change files in the folder.
- **SEC10 (low):** an archive taken from the inbox was moved, so on Linux it stayed the sender's file. It is now copied into a new file of Blackbox's own.
- **READ1:** sharing the reports with a group works only on a folder that only root can change, and never through a link.

`tray_groups`: members must also be Administrators, as before. This is now written in the settings guide.
