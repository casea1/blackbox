## What's new

### Fix list (FIX1)

- Each report folder now has `fix-list.html`, a page for the administrators who fix what the report found. It lists every system with something to fix, CAT I findings and STIG gaps first:
  - audit settings that don't match the STIG;
  - Blackbox's own advice, marked as advice;
  - logs too small to keep their events;
  - open SCAP findings by CAT, with the benchmark's fix text.
- Fixes that can be run as a command have it ready to copy with a **Copy** button: `auditpol`, `wevtutil`, the Linux audit-rule steps, and OpenSCAP fix scripts. Group Policy settings are given too.
- No events and no people are in it.
- Print it and choose "Save as PDF" for a PDF.
- `blackbox fixes --out FILE` writes the page on its own, for the time since the last report. It makes no report and leaves the schedule alone.

## Upgrade

- Upgrade as usual.
- Fix text for SCAP findings shows for scans read after the upgrade, from results files that include it. Some scanners leave it out of their results file; for those findings the page says to look up the Vuln ID in STIG Viewer.

## Not verified live

- Tested with the 30-system demo report and automated tests only, not on a live collector.
- Not checked against real SCC result files: the test files have no fix text, so whether SCC results carry it is not confirmed.
- Not tested on a real system: whether each copied command runs as written.
