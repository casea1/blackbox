## What's fixed

- **Linux (AlmaLinux, Rocky, RHEL): `sudo blackbox` said "command not found".** Their sudo leaves `/usr/local/bin` out of its path. Setup (and an upgrade) now also links `/usr/bin/blackbox` to the program, so `sudo blackbox status` works without the full path. A file named `/usr/bin/blackbox` that is not a link is left alone.

## Not verified live

- Tested in automated tests only; not yet on a live AlmaLinux system.
