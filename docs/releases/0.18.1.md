## What's new

Owner requests from 7 Oct 2026. Blackbox still only reports; it changes no system or audit settings.

### Status icon

- **Simpler menu.** The menu shows only the status line, for example "Collecting every 15 minutes · last 14:05 · next report Wed 00:00", or what is wrong. Per-system items such as "Audit settings: 2 to fix on WS-13" are no longer listed; they are in the report and in `blackbox status`.
- **No coloured dot.** The icon is the plain Blackbox logo whatever the state. The status line and the notifications tell you how things are.
- **"Collect now" says when it's done.** Before, it said the status would update when collection finished, but nothing checked until the next one-minute refresh. The icon now checks every 5 seconds (for up to 30 minutes) and notifies "Collection finished (14:05)." A run that fails is notified as "the last run failed", as before.

### Audit health

- **Gaps as a table.** The large gap cards are replaced by a compact table with one row per gap: the gap, its STIG ID, the systems (each a link to its settings) and the result. Click a gap to see what it means and how to fix it.

Release files are still unsigned: the signing secrets (A10) have not been set yet.
