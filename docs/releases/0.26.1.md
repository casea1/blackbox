## What's new

### Windows setup at a command prompt or over SSH

- The setup file (`Blackbox-Setup-…exe`) is a windowed program, so cmd.exe does not wait for it: when it asked a question, such as whether to upgrade, cmd took the answer as a command ("'y' is not recognized…").
- The release now also includes **`blackbox-0.26.1-windows-amd64.exe`**, the same program as a console program, the one the setup file installs. From an elevated cmd prompt, or an SSH session to the computer, run `blackbox-0.26.1-windows-amd64.exe install` and answer the questions as on Linux. It installs and upgrades the same way, and works with `--yes` for scripts.
