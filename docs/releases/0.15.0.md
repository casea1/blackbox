## What's new

### Original logs on another volume

- **`archive_dir`.** The original logs (`.evtx`, Linux audit and system logs) of this computer and, on a collector, of every sender wait until the next **scheduled** report moves them into its folder. With weekly reports, that is up to a week of every computer's logs. Until now they waited in the data folder (`C:\ProgramData\Blackbox\archives`). They can now wait on another volume: setup asks "Where should the original logs wait for the next report?" (a new **Original logs** page in the setup window), and `blackbox config set archive_dir D:\BlackboxLogs` changes it later. The exports made at each collection go there too. Archives already waiting in the data folder still go into the next report. `blackbox config` and `status` show where they wait.

### Reports

- **"Manual" instead of "interim".** A report run by hand (`blackbox report`, or **Make a manual report…** in the tray) is now called a manual report everywhere, and its folder ends in `_manual`.
- **Folder names.** Report folders are named after the site name set in setup, e.g. `2026-10-05_0000_Lab-3-LAN`. Without a site name, a report on one computer is named after it, and a collector's report after the collector, instead of `4-systems`.

Release files are still unsigned: the signing secrets (A10) have not been set yet.
