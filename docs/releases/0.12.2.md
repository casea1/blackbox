## What's new

### Original logs

- **Saved before a log overwrites them.** At every collection, Blackbox checks each log it saves: on Windows, whether the event log is full and set to overwrite; on Linux, whether auditd has rotated the audit log. If a log could overwrite events not yet saved before the next collection, the original logs are saved straight away instead of waiting for the daily save. A small or busy log is saved every run; a properly sized one is still saved once a day.
- **Gaps are reported.** If a full log had already overwritten part of the period when it was saved, the archive records it. The report's Original logs page shows "Missing <from> – <to>: overwritten before it was saved", Audit health has a warning, and `summary.json` lists it under the archive's `gaps`. `blackbox status` says **LOGS INCOMPLETE** and exits with code 4 for 14 days.
